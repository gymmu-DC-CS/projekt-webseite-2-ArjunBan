Allgemein: Ich habe mit der KI Claude gearbeitet. ICh habe diese KI für diesen Auftrag benutzt, weil es gute Bewertungen hatte und mir von mehreren Personen emopflen wurde.
1. CSS Variablen
Ich wollte nicht jede Farbe immer einzeln eintippen. Die KI Claude hat mir gezeigt dass man Farben einmal oben speichern kann und dann überall benutzen kann. Das hat mir viel Zeit gespart. Mit :root kann man Variablen wie --accent: #00f0ff definieren und sie überall mit var(--accent) verwenden. Das wusste ich nicht.

2. Sticky Navbar
Ich wollte dass die Navigationsleiste oben bleibt wenn man scrollt. Das war mir neu man braucht nur position: sticky und top: 0 dafür. Die Ki Claude hat mir auch gezeigt wie man einen Glaseffekt macht damit es moderner aussieht.

3. Z-index
Ich wusste nicht warum der Inhalt manchmal über die Navbar gerutscht ist. Claude hat erklärt dass z-index bestimmt welches Element vorne liegt. Je höher die Zahl desto weiter vorne ist es.

4. Flexbox
Ich wollte das Logo links und die Links rechts haben. Mit display: flex und justify-content: space-between geht das automatisch. Das benutze ich mehrmals auf der Website.

5. CSS Grid
Ich wollte Karten nebeneinander anzeigen ohne alles selbst zu berechnen. Mit CSS Grid macht das der Browser automatisch — er schaut wie viele Karten passen und ordnet sie selbst an.

6. Data-Attribute
Ich wollte Filter-Buttons die nur bestimmte Karten zeigen. Claude hat gezeigt dass man in HTML eigene Attribute erfinden kann wie data-category="writing". JavaScript liest das dann aus und versteckt alles andere.

7. Farbverlauf im Hintergrund
Ich wollte einen leuchtenden Effekt hinter dem Titel. Mit radial-gradient kann man das machen — eine Farbe in der Mitte die nach aussen hin unsichtbar wird. Ich habe Cyan und Pink kombiniert weil das zum Design passt und allgemein futuristisch aussieht.
